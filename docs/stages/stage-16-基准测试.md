## 基准的价值即刻兑现：发现并修复真实 P1 缺陷

首轮全量矩阵跑出 **5.6% 误拦截**（缩减矩阵因时序运气未复现）：
- **根因**：`EvidenceRecorder` 的证据时间戳是毫秒级 `Date.now()`；快速内存栈上 edit 与 passing test 落进同一毫秒，引擎 `at > since` 的严格比较把通过测试误判为改动前证据 → 合规回合被误 BLOCK（间歇性、难复现）。
- **修复**：记录时逻辑时间戳严格递增（`at = max(at, last+1)`），因果序在比较值上成立；事件形状不变。
- **回归测试**：同毫秒证据 → 引擎 PASS；全量基准复跑 **误拦截 0.0%**。
- 这正是计划书 §Phase 18 的立意：让"有用而非装饰"用数字证明——装饰性指标永远发现不了这种缺陷。
